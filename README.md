# Лист Поднебесной

Фронтенд интернет-магазина китайского чая на Next.js. Laravel API находится в отдельном проекте.

## Требования

- Node.js 20.9+
- npm

## Локальный запуск

```bash
npm install
npm run dev
```

Создайте `.env.local` и укажите адрес API:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000/api
```

Основные npm-команды: `npm run dev`, `npm run build`, `npm start`, `npm run lint`.
Подробная схема фронтенда приведена в [README_FRONTEND.md](README_FRONTEND.md).
